## 兼容性说明：RELOADED 自述

RELOADED 解释，初版使用了一项只适用于 Windows XP SP2 的技术，因而不能支持其他一些 Windows 版本。说明举到 Windows 2000、2003、XP SP1、未更新的 XP，以及 64 位 XP；这份 OS FIX 面向这些兼容性问题。此处记录的是发行者对修复用途的解释，并非本项目逐一运行这些系统所得的测试结果。

## 对 DEViANCE 的回应：RELOADED 当事方说法

从这份回应可知，RELOADED 称 DEViANCE 指责其使用 Loader。它将该指责斥为：

> ignorant bullshit as always

可译述为“照旧是无知的胡扯”。RELOADED 接着主张：启动位置增加的代码用于正确加载导入表，自己的发行不使用驱动、可以调试；光盘检查已经不存在，而非被欺骗过去。随后，它让对方参看 DEViANCE 自己发行的《Cricket 2005》，将其作为 Loader 的例子反击。

这些技术描述、评价和反例，均须写成 RELOADED 的说法。仅有这份回应，不等于已经取得 DEViANCE 原始批评全文；本项目也未进行二进制审计，不能据此裁定哪方的技术判断正确。
