# 素材库

- [本地素材浏览](00_ledger/素材浏览.html)：缩略图、视频与声音文件入口，可按编号、作品、作者和许可搜索。
- [下载与检索记录](../document/素材下载记录.md)：已取得的重点素材、选用建议与仍存在的缺口。
- [素材登记 CSV](00_ledger/素材登记.csv)：每个实际媒体文件的来源、尺寸、时长、作者、使用条件与 SHA-256。
- [完整媒体元数据](00_ledger/assets.json)、[来源快照清单](00_ledger/source_inventory.json)。
- [完整准备清单](../document/媒体素材清单.md)：OP／FL／EX／AU／MG 编号的定义和叙事用途。

`01_sources/` 保存原始史料与元数据；`02_footage/` 保存实际视频；`03_stills/` 保存图片与 PDF 页面导出；`05_audio/` 保存声音；`07_selects/` 保存预览缩略图。

下载成功只表示文件已取得。版权／使用条件和史料准确性分别核对，不能互相替代。CSV 中相同 SHA-256 的文件注明重复关系；浏览页合并完全相同的重复文件。原始文件、截图、网页与视频缩略图分别登记，不将缩略图算作已取得视频。

小于 10 MiB 的媒体文件可正常提交；大于或等于 10 MiB 的文件按具体路径写入 `.gitignore`，不会整目录或按视频扩展名一律忽略。新增素材后，在项目根目录运行 `python3 media/00_ledger/update_media_ignore.py` 刷新名单；可用 `--max-mib 20` 调整阈值。Git 本身不支持按大小动态忽略，因此新增大文件需要先刷新名单。登记表、检索记录和采集脚本仍可版本管理；忽略规则不会删除本地文件。

采集脚本用于复查来源，不建议无差别重跑全部下载。`collect_sources.py` 抓取文档中已登记的来源；`collect_assets.py` 取得来源图片与官方商店图片；`collect_more.py` 收集部分官方预告与 Commons 文件。网络结果可能变化，脚本产生的新候选仍需人工复核。

补充或核验文件后，可在项目根目录运行 `python3 media/00_ledger/build_catalog.py` 更新登记和浏览页。脚本读取已经确认下载成功的文件，不会把失败请求视为成功素材。
