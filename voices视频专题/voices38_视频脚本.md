## 二、时间线与配音使用

本脚本给出新版完整设计，镜头编号和旁白以本文为准。“视频文稿配音（前2幕）”属于旧版录音；前两幕工程已改用 `videoVoices/` 中的新录音。下文时码表仍是粗剪预估，实际剪辑按配音长度和本节间隔约定重算。

| 项目 | 制作安排 |
| --- | --- |
| 合成 | 保留 `V38Full`、`V38Act1`、`V38Act2`、`V38Thumb` 入口；制作后续时新增 `V38Act3`—`V38Act10`，这里是合成规划 |
| 镜头 | 每镜用本文编号标记；默认硬切，翻面、倒带、纸面切换在该镜头预留时间内完成 |
| 配音 | 本文所有“旁白”块是唯一对词依据；已录句子只有与新版文字、语气一致时才复用。新增和改写句重录，尤其首发窗口、社区评论及开场说明 |
| 时长 | 配音确认后，按“前置留白＋实际配音＋必要句间隔＋后置留白”重算，按 60 fps 向上取整；预估时长不作为镜头最低时长，配音保持原速 |
| 字幕 | 使用新版文稿文本，语音时间戳只用于对齐；按分镜拆开的旁白在合成中仍保持自然连续 |
| 原声 | 游戏原声低于旁白；对白密集的宣传片段静音。缺实录的镜头已有文字／图解替代，可先完成粗剪 |

### 段落间隔与停顿约定

**有配音的镜头以实际录音为时长依据。** 本文表格和镜头标题里的秒数、帧数、起止时码用于粗剪规划，不要求镜头播满这些数值。录音提前结束时，按以下留白结束镜头并衔接下一段；后续镜头的起点随剪辑顺移。

| 场景 | 默认间隔／留白 | 剪辑方式 |
| --- | --- | --- |
| 普通跨镜头段落 | 上一镜后置约 0.15 秒（9f）＋下一镜前置约 0.10 秒（6f），合计约 0.25 秒（15f） | 以上一段配音结束到下一段配音开始计，不再额外叠加“转场停顿” |
| 同一镜头内的独立录音 | 两段之间约 0.15 秒（9f） | 保持语意连贯，不给每个短句重复加一套前后留白 |
| 一段连续录音跨两个镜头 | 切镜处不另加间隔 | 在原录音的合适停顿处切画面；音频、字幕保持同一个来源时钟，避免重复或漏掉语句 |
| 名字、数字或轻笑点落定 | 旁白后置约 0.25—0.35 秒（15—21f），按具体镜头选择 | 只给需要强调的位置；普通段落继续使用默认间隔 |
| “第一次尝试”等独立情绪落点 | 旁白后置约 0.60 秒（36f） | 单镜明确标记，回扣时沿用同样节奏，不推广到普通段落 |
| 片名与幕间转场 | 独立设置短时长；当前片名卡约 2.30 秒，倒带转场约 2.20 秒 | 这段时间已经包含文字入场、阅读与离场，不在两端再补长停顿 |

上述数值是额外剪辑留白的默认值。原录音自身已有的句间停顿、首尾静音也应计入实际听感；已经足够时，减少外加留白。开场黑场、明确的悬念或段落收束可单独处理，例外应在相应镜头中说明。

工程计算有配音镜头时，使用“前置留白＋各段实际配音时长＋必要句间隔＋后置留白”，不使用 `max(预估镜头时长, 配音与留白之和)` 将镜头强行撑满。按 60 fps 向上取整只处理帧边界，不能变成额外的半秒或一秒停顿。片名等无配音镜头才单独指定完整时长。

画面动作跟随旁白完成：入场可与旁白同时进行，重点图解、引文逐段展开，尽量在对应语句结束前落定。需要阅读空间时，先调整分卡、字号、高亮和入场时点；确需旁白后的阅读停顿，再在该镜头单独注明。下文“留半拍”“停一拍”等节奏提示服从本节，不自动换算成每段额外静置 1—2 秒。

检查剪辑时，重点听“一句结束—下一句开始”的连续节奏，同时检查新切点有无截断尾音、字幕或关键动画。普通衔接通常约 0.25 秒；超过 0.5 秒应逐处确认是否有明确的叙事或阅读用途。当前前三幕采用上述规则，A1-01 → A1-02 的配音间隔约为 0.25 秒。

镜头中提到的缓推一般每秒不超过 1.5%；关键词快推约 10—12 帧。光标按 30 帧亮、30 帧灭；文字长句整体或分行显现，只对短名、字段、字母变化使用逐字效果，避免阅读追不上旁白。所有动画按帧驱动。

沿用现有字体、`NameCursor`、来源与字幕系统；前三幕的材料运动、原文阅读、请求删减和游戏镜头使用本次重做的实现。后续技术图、名单对照、35% 进度条、字母替换与双时间线也按具体叙事设计，避免套用静止卡片矩阵。旧版“40 GB 比例尺”和“保质期贴纸”不再进入新版成片。
