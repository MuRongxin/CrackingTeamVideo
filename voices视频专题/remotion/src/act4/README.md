## 维护与验证

`python3 scripts/prepare-act4.py` 只准备第四幕录音和五张衍生图。默认保留已调字幕；`--captions` 才重建初始对齐。字幕使用当前文稿，长句按本地 ffmpeg 测得的停顿对齐，109、126 两段连续语音保留可手调的初始短句切点；未用识别文本改写原稿。

`npm run typecheck`、`node scripts/check-act4.cjs` 检查类型、录音原件哈希、136 段录音完整使用、字幕边界、语音间隔、四幕总长与独立／连续版一致性，并抽查第四幕 40 个关键帧。

`node scripts/check-studio-act4.cjs` 直接检查运行中的 Studio、原图加载、字体、前后拖动和连续版，图片保存在忽略的 `.qa/`，不会导出成片。
